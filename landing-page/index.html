Парсер организаций из Яндекс.Карт

Собирает название, адрес, рейтинг, категории и телефон. Экспорт в Excel. Десктопный интерфейс на pywebview.

Ранняя альфа. Не готов к использованию. Парсер стабильно собирает около пяти карточек, после чего Яндекс блокирует браузер белым экраном. Обход защиты не реализован.
Открыть на GitHub Известные проблемы

Установка

  1. Клонировать репозиторий

    Нужен Python 3.10 или новее.

  2. Создать окружение

    Selenium, pywebview, openpyxl.

  3. Запустить

    Откроется десктопное окно.

# клонирование и окружение
git clone https://github.com/manypon/parser-yandex.map.git
cd parser-yandex.map
python -m venv .venv
source .venv/bin/activate

# зависимости
pip install -r requirements.txt

# запуск
python main.py

Известные проблемы

  • Белый экран после примерно пяти спарсенных карточек. Яндекс детектит navigator.webdriver.
  • Нет stealth-режима, ротации User-Agent и прокси.
  • Больше нескольких десятков карточек подряд собрать не получится.
  • Селекторы привязаны к текущей вёрстке — при обновлении сайта могут отвалиться.

Когда пригодится

Для небольшой выборки организаций: аналитика, исследование рынка, обогащение базы. С поправкой на то, что каждые пять карточек парсер придётся перезапускать руками.

Если нужно больше — смотри в сторону invisible-playwright или camoufox.
