# Changelog

Все значимые изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.1] - 2025-09-30

### Fixed
- Выбор Яндекс.Браузера в списке браузеров — теперь корректно находится и запускается.
- Мелкие багфиксы в интерфейсе и обработке ошибок.

## [1.0.0] - 2025-09-29

### Added
- Первый публичный релиз.
- Десктопный интерфейс на pywebview с тёмной темой.
- Сбор карточек организаций из Яндекс.Карт: название, рубрика, адрес, телефон, рейтинг, ссылки.
- Поддержка браузеров: Chrome, Яндекс.Браузер, Edge, Firefox.
- Экспорт результатов в CSV, XLSX, JSON, HTML.
- История запусков и живой журнал найденных организаций.
- Обработка капчи и «белого экрана» с возможностью продолжить сбор вручную.
- Разделение данных на профили браузеров, логи и экспорт в папке `data/`.
