# Установка и запуск

Подробная инструкция по установке, запуску и решению типовых проблем.

> **Проверено на:** Windows 10 и Windows 11.
> На macOS и Linux приложение, скорее всего, заработает (пути к браузерам в `browser_manager.py` учитывают эти системы), но автором не тестировалось.

## Требования

### Обязательно
```
| Компонент | Версия | Зачем |
|---|---|---|
| **Python** | 3.10 или новее | Язык проекта. Нужен именно 3.10+, потому что код использует синтаксис `X \| None` в аннотациях типов. |
| **pip** | идёт в комплекте с Python | Установка зависимостей. |
| **Хотя бы один браузер** | — | Парсер работает через реальный браузер на вашем компьютере. Подробнее — в разделе [Поддерживаемые браузеры](#поддерживаемые-браузеры). |
| **Интернет** | — | Парсит сайт, куда же без него. |
```

### Не обязательно, но полезно

- **Google Chrome** — самый стабильный вариант, с ним меньше всего проблем с драйвером.
- **Терпение** — Яндекс.Карты активно защищаются от парсинга. Иногда придётся ждать или проходить капчу руками.

### Как проверить, что Python установлен

Открой командную строку (или PowerShell) и выполни:

```bash
python --version
```

Должно вывести `Python 3.10.x` или новее. Если пишет «команда не найдена» или версия ниже 3.10 — установи Python с [python.org/downloads](https://www.python.org/downloads/).

> **Важно (Windows):** при установке Python поставь галочку **«Add Python to PATH»** на первом экране установщика. Без неё `python` не будет работать в командной строке, и придётся прописывать путь вручную.

## Установка

### Шаг 1. Скачать проект

Через Git (рекомендуется):

```bash
git clone https://github.com/manypon/parser-yandex.map.git
cd parser-yandex.map
```

Без Git — нажми на странице репозитория зелёную кнопку **Code → Download ZIP**, распакуй архив и открой папку в командной строке.

### Шаг 2. Создать виртуальное окружение

Виртуальное окружение изолирует зависимости проекта от остальной системы. Это не обязательно, но настоятельно рекомендуется — иначе библиотеки проекта могут конфликтовать с другими Python-проектами на компьютере.

**Windows (PowerShell или cmd):**

```bash
python -m venv .venv
.venv\Scripts\activate
```

После активации в начале строки появится `(.venv)` — это значит, что окружение активно.

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Если при активации в PowerShell появляется ошибка про «выполнение сценариев отключено» — выполни один раз от имени администратора:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### Шаг 3. Установить зависимости

```bash
pip install -r requirements.txt
```

Ставятся четыре пакета:

- `selenium` — управление браузером;
- `pywebview` — окно приложения с интерфейсом;
- `openpyxl` — экспорт в Excel;
- `selenium-stealth` — базовое скрытие следов автоматизации.

Установка занимает 30–60 секунд в зависимости от скорости интернета.

### Шаг 4. Проверить, что всё встало

```bash
python -c "import selenium, webview, openpyxl; print('OK')"
```

Если вывело `OK` — всё в порядке. Если `ModuleNotFoundError` — вернись к шагу 3.

## Запуск

Из папки проекта, с активированным виртуальным окружением:

```bash
python main.py
```

Откроется окно приложения с интерфейсом. При первом запуске Selenium Manager автоматически скачает драйвер под твой браузер — это займёт 10–30 секунд, в следующий раз будет мгновенно.

> **Примечание.** Selenium Manager качает драйверы в системную папку (`%USERPROFILE%\.cache\selenium` на Windows). Это нормально — не удаляй её, иначе при следующем запуске драйвер скачается заново.

### Что дальше

1. В главном окне заполни **«Что ищем»** (например, `СПА`) и **«Город»** (например, `Москва`).
2. Укажи, **сколько найти** — начни с 50–100, чтобы проверить, что всё работает.
3. Выбери **браузер** из доступных (см. следующий раздел).
4. Нажми **«Запустить»**.

Прогресс отображается в верхней части окна. Найденные организации появляются в журнале справа, а по завершении их можно выгрузить в CSV, XLSX, JSON или HTML.

## Поддерживаемые браузеры

Парсер работает **через реальный браузер на твоём компьютере**, запуская его с отдельным профилем приложения. Это значит:

- твои личные вкладки, куки и история **не затрагиваются**;
- профиль хранится отдельно, в папке `data/profiles/<браузер>/`.

### Какие браузеры поддерживаются
```
| Браузер | Движок | Комментарий |
|---|---|---|
| **Google Chrome** | Chromium | Рекомендуется. Самый стабильный вариант. |
| **Яндекс.Браузер** | Chromium | Поддерживается, но иногда версия протокола расходится с чистым Chromium, и драйвер может не запуститься. Если так — используй Chrome. |
| **Microsoft Edge** | Chromium | Работает так же стабильно, как Chrome. |
| **Firefox** | Gecko | Поддерживается, но работает чуть медленнее и использует другой механизм обхода автоматизации. |
```

### Что значит «браузер не найден»

При первом запуске приложение ищет установленные браузеры в типичных местах:

- `PATH` — если браузер там есть;
- стандартные папки установки (`C:\Program Files\...`, `/Applications/...` и т. д.);
- для Яндекс.Браузера дополнительно — `%LOCALAPPDATA%\Yandex\YandexBrowser\Application\browser.exe`.

Если браузер установлен в нестандартное место — приложение его не увидит. В этом случае выбери Chrome или Edge, они ставятся в стандартные пути.

### Режимы запуска

В интерфейсе есть два режима:

- **«С окном»** — браузер видно на экране. Медленнее, но защите сайта сложнее отличить автоматизацию от живого пользователя.
- **Headless** — браузер работает в фоне. Быстрее, не мешает работать за компьютером, но детектится чаще.

Для сбора данных с Яндекс.Карт **используй «С окном»**. Headless у Яндекса палится почти сразу.

## Где хранятся данные

Все данные приложения лежат рядом с исходниками, в папке `data/`. Ничего не пишется в системные папки без твоего ведома.

```
data/
├── profiles/     # профили браузеров (по одному на каждый браузер)
├── logs/         # текстовые логи сессий
├── exports/      # выгруженные CSV, XLSX, JSON, HTML
├── settings.json # настройки приложения
└── history.json  # история запусков
```

### Как всё почистить

- **Логи** — просто удали файлы из `data/logs/`. Приложение создаст новые при следующем запуске.
- **Экспорт** — удали из `data/exports/`. Ничего не сломается.
- **Профили браузеров** — если парсер начал вести себя странно и подозреваешь, что Яндекс тебя запомнил по кукам, удали `data/profiles/<браузер>/`. Профиль создастся заново. **Твои личные данные Chrome/Firefox при этом не тронутся** — это отдельная папка.
- **Настройки и историю** — можно удалить `data/settings.json` и `data/history.json`. Приложение восстановит их с дефолтными значениями.

### Как открыть папку с данными

В интерфейсе → **Настройки** → **«Открыть папку с логами»** или **«Открыть»** рядом с полем «Папка для файлов».

## Если что-то не работает

### `python: команда не найдена`

Python не в `PATH`. Если ставил только что — переустанови, поставив галочку **«Add Python to PATH»**. Если уже стоит — добавь в `PATH` вручную через «Изменение переменных среды текущего пользователя».

### `pip install -r requirements.txt` падает

Скорее всего, старая версия pip. Обнови:

```bash
python -m pip install --upgrade pip
```

Если ошибка про отсутствующий компилятор — попробуй поставить пакеты по одному:

```bash
pip install selenium
pip install pywebview
pip install openpyxl
pip install selenium-stealth
```

Так будет видно, какой именно пакет ломается.

### `selenium.common.exceptions.SessionNotCreatedException`

Selenium Manager не смог подобрать драйвер под твой браузер. Варианты:

1. **Обнови браузер** — если Chrome старой версии, обнови до последней.
2. **Обнови Selenium** — `pip install --upgrade selenium`.
3. **Попробуй другой браузер** — если ломается Яндекс.Браузер, переключись на Chrome.
4. **Удали кэш драйверов** — `%USERPROFILE%\.cache\selenium` на Windows, `~/.cache/selenium` на Linux/macOS. При следующем запуске скачается заново.

### Белый экран после нескольких карточек

Это **известная проблема**, а не баг твоего кода. Яндекс детектит автоматизацию через `navigator.webdriver` (Selenium по стандарту W3C обязан выставлять этот флаг) и перестаёт отдавать контент.

Что делать:

1. **Подожди минуту** и нажми **«Продолжить»** в окне предупреждения — иногда помогает.
2. **Уменьши скорость** — в настройках увеличь паузу между запросами до 8–15 секунд.
3. **Собери меньше за раз** — 30–50 карточек вместо 1000. Между сессиями перезапускай приложение, чтобы менялся профиль.

Радикальное решение — переход на stealth-сборку Firefox (`camoufox` или `invisible_playwright`). Оно запланировано в следующих версиях.

### Капча

Если Яндекс показал капчу — приложение поставит сбор на паузу. Открой окно браузера, пройди капчу руками, вернись в приложение и нажми **«Продолжить»**. Сбор продолжится с того же места.

### Приложение не закрывается

Закрытие окна сворачивает приложение в трей (если включена настройка **«Сворачивать при закрытии»**). Выход — через трей, правой кнопкой → «Выход», или отключи эту настройку.

### Ничего не помогает

Открой issue на GitHub: [github.com/manypon/parser-yandex.map/issues](https://github.com/manypon/parser-yandex.map/issues). Приложи:

- версию Python (`python --version`);
- версию браузера;
- текст ошибки (если есть);
- последний файл из `data/logs/`.
