# Yandex Parser

⚠️ **Статус: ранняя альфа. Не готов к использованию.**

Парсер данных из Яндекс.Карт. Собирает информацию об организациях: название, адрес, рейтинг, категории, телефон.

## ⚠️ Известные проблемы

**Парсер работает нестабильно. Это не баг, а следствие защиты Яндекса.**

- **Белый экран каждые ~5 спарсенных карточек.** Яндекс детектит автоматизацию через `navigator.webdriver` (Selenium по стандарту W3C выставляет этот флаг). После детекта сайт просто не отдаёт контент — страница белеет, и её приходится перезагружать вручную.
- **Обход защиты не реализован.** В текущей версии нет stealth-режима, ротации User-Agent и прокси.
- **Масштабирование невозможно.** Собрать больше нескольких десятков карточек подряд не получится — упрёшься в блокировку.

Если тебе нужен рабочий парсер Яндекс.Карт **прямо сейчас** — этот проект не подходит. Смотри в сторону `invisible-playwright` или `camoufox`.

## 📖 О проекте

Инструмент для сбора данных об организациях из Яндекс.Карт. Предназначен для аналитики, исследования рынка и обогащения баз данных.

## 🛠️ Стек

| Компонент | Технология |
|---|---|
| Язык | Python 3.10+ |
| Браузер | Selenium 4.15+ |
| Интерфейс | pywebview |
| Экспорт | openpyxl |

## 📦 Установка

```bash
git clone https://github.com/manypon/yandex-parser.git
cd yandex-parser
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## 🚀 Запуск
```
python main.py
```
Откроется десктопное окно (pywebview) с интерфейсом.
