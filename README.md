# 2GIS Parser

> ⚠️ **Статус проекта:** в активной разработке. API, структура и функциональность могут изменяться без предупреждения.

Парсер данных из 2GIS — инструмент для сбора и структурирования информации об организациях, заведениях и точках на карте.

---

## 📖 О проекте

Инструмент для сбора и структурирования информации об организациях, заведениях и точках на карте из сервиса 2GIS. Предназначен для аналитики, исследования рынка, обогащения баз данных и других задач, требующих актуальной информации о бизнесе.

---

## ✨ Планируемые возможности

- 🔍 Поиск организаций по категориям, ключевым словам и геолокации
- 📋 Сбор карточек: название, адрес, телефон, сайт, соцсети, часы работы
- ⭐ Сбор рейтингов, отзывов и количества оценок
- 🗂️ Категории и рубрики организаций
- 📍 Координаты и привязка к районам/городам
- 🖼️ Изображения и фотогалереи (опционально)
- 💾 Экспорт в JSON / CSV / Excel
- 🕒 Поддержка прокси и ротации User-Agent
- ⚙️ Конфигурируемые параметры запросов (город, категория, лимиты)

---

## 🖥️ Интерфейс

Планируется два варианта использования:

### Веб-дашборд
Панель управления в браузере на базе **Flask**. Запускается локально, открывается по адресу в браузере:
- запуск парсинга
- настройка параметров
- просмотр и выгрузка результатов

### Desktop-приложение
Отдельное `.exe`-окно для локального запуска без необходимости поднимать сервер вручную.

> Возможно, будут реализованы оба варианта.

## 🛠️ Стек (предварительно)

| Компонент | Технология |
|-----------|------------|
| Язык | Python 3.10+ |
| HTTP | `httpx` / `requests` |
| Парсинг | `selectolax` / `BeautifulSoup` |
| Данные | `pandas`, `pydantic` |
| Веб-интерфейс | `Flask` |
| Desktop-сборка | `PyInstaller` *(планируется)* |
| Асинхронность | `asyncio` *(планируется)* |
